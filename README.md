# Finite State Machine Designer

Hi! this is an app for designing finite state machines. Made by utilizing Canvas API, JavaScript, HTML, CSS.

![Image](https://i.ibb.co/HGqTSQc/file-2024-07-17-07-07-01.png)

## Inspiration

Evan Wallace, the co-founder of Figma had made a FSM Designer back in 2011. I wanted to recreate that.
